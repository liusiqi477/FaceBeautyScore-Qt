# FaceBeautyScore-Qt
基于 C++ Qt + OpenCV + Dlib 实现的人脸智能颜值评分图形化系统，高级语言程序设计课程大作业。
## 项目简介

本项目支持本地图片、摄像头实时视频两种测评模式，依托 Dlib 提取 68 个人脸关键点，结合庭衡五眼、五官对称度、皮肤纹理等美学指标构建多维度打分模型。引入高斯评分函数与 EMA 平滑算法优化评分效果，搭配 Qt 可视化交互界面。
## 核心亮点
1. 双测评模式：静态图片分析、摄像头实时动态评分
2. Dlib 68点人脸关键点定位，仿射变换人脸对齐，消除侧脸、倾斜带来的计算误差
3. 五大美学维度量化打分，总分区间0~100，评分标准贴合面部黄金比例
4. EMA指数平滑+稳定帧锁定机制，解决实时画面分数剧烈跳动问题
5. 高内聚低耦合模块化设计，检测、评分、界面、特征分析类完全解耦
6. 可视化交互：画面实时绘制人脸关键点，分项分数与五官文字评价同步展示
